# California-Sales-Trends-Power-BI-Dashboard

🏷️ Project Title / Headline :- 
California Sales Trends Analysis using Power BI

📝 Short Description / Purpose :- 
This Power BI dashboard analyzes sales performance across California, offering insights into profitability, product trends, and regional sales distribution. It helps stakeholders understand which products and cities drive revenue, and how sales evolve over time.

🛠️ Tech Stack :- 
- Power BI – for data modeling, visualization, and dashboard design
- DAX (Data Analysis Expressions) – for custom measures and time intelligence
- Excel/CSV – as source files for importing sales data

🌟 Features / Highlights
- Profit Conversion Rate: Dynamic measure showing profit as a percentage of sales
- Product-Level Analysis: S.P, C.P, and Profit breakdown for each Product ID
- Yearly and City-Wise Sales: Total Sales Price aggregated by year and city
- Time-Based Trends: Sales and profit trends visualized by year and quarter
- Top Performers: Top 10 products by quantity sold
- Profit Distribution: Product-wise total profit measure for strategic decisions
- Interactive Filters: Slicers for year, city, and product selection
